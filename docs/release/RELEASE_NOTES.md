First public release of BBR2 Online: online multiplayer for Beach Buggy Racing 2 on PC (Steam version for Windows).

**Install:** download `BBR2Online_0.10.0.zip` below and extract it into the game folder (Steam > right-click the game > Manage > Browse local files). Then select **Online** in the main menu. Everyone in a lobby must use the same version. The full guide is in `README.txt` inside the zip.

**What's in this version**
- **Lobby** in the game's own menus: 8 player cards with Open, Bot and Closed slots, track choice or Random, Same Car for All, and chat.
- **Joining:** by lobby code, Steam invite or IP address. Steam relay is supported, so no ports need to be opened.
- **Synchronised start:** common clock and countdown lock.
- **Host-decided results:** finished players wait up to 30 s for the others, and everyone sees the same table.
- **Leaving and late joining:** the AI takes over if a player leaves; players who join during a race wait in the lobby for the next one.

**Known limits**
- Race mode only.
- One player per PC.
- Car contact can look slightly different on each screen when the connection is bad.

Files:
- `BBR2Online_0.10.0.zip`: the mod (for players).
- `BBR2Online_0.10.0_source.zip`: the same source as this repository.
